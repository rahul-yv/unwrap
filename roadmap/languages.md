# Languages and topic order

Every language folder under `languages/` follows the same 18-topic sequence, so learners can map concepts across languages.

| # | Topic | Folder |
|---|-------|--------|
| 1 | Variables | `01_variables` |
| 2 | Data types | `02_datatypes` |
| 3 | Operators | `03_operators` |
| 4 | Conditionals | `04_conditions` |
| 5 | Loops | `05_loops` |
| 6 | Functions | `06_functions` |
| 7 | Collections | `07_collections` |
| 8 | Object-oriented programming | `08_oop` |
| 9 | Error handling | `09_errors` |
| 10 | Files and I/O | `10_files` |
| 11 | Modules and packages | `11_modules_packages` |
| 12 | Testing | `12_testing` |
| 13 | Networking and APIs | `13_networking` |
| 14 | Databases | `14_databases` |
| 15 | Concurrency | `15_concurrency` |
| 16 | Security basics | `16_security` |
| 17 | Mini projects | `17_projects` |
| 18 | Interview prep | `18_interview` |

## Cross-language comparisons

Once at least three languages have a topic complete, add a comparison note under `projects/comparisons/<topic>.md` showing the same concept side by side (syntax, typing, memory model, concurrency model, stdlib idiom — whichever are relevant to that topic).
